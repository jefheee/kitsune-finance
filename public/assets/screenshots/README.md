# Screenshots Directory

Store your application interface screenshots here. These files are referenced by the project's root `README.md`.

## Recommended Filenames

- `01_dashboard.png`: Personal Wealth Dashboard (KPIs, cash flow, spending curve, recent activity)
- `02_cards.png`: Credit Card Wallet (Apple Wallet stack, master-detail layout, installment breakdown)
- `03_investments.png`: Investment Portfolio (Macro gauges: Selic/CDI/IPCA, asset allocation, yield forecast)
- `04_shared_space.png`: 360 Shared Space (Joint family balance, fair-share split calculator, goals simulator)
- `05_kitsune_ai.png`: Kitsune AI Advisor (Multi-step reasoning pacing, audio waveform, receipt OCR)
- `06_global_search.png`: Global Finance Search (Ctrl+K modal with merchant dossiers and category breakdown)

## Privacy Best Practice

Before capturing screenshots of your live accounts:
1. Toggle the eye icon in the AppShell header to enable Global Privacy Mode (`isPrivacyMode = true`).
2. All sensitive balances will be masked as `R$ ••••••`, ensuring zero real monetary figures are committed to version control.
